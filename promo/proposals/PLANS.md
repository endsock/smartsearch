# Smart Search 宣传片：三个方案

主角是 Clawd（Claude Code 终端 logo 里的像素小家伙），在片子里扮演"正在用 Smart Search 的 AI 助手"。
三个方案共用一条剧情冲突：**前半段用内置搜索处处卡壳，换上 Smart Search 之后一路丝滑**。
画面本身的流畅度也跟着变：卡壳的部分按 8 帧步进、发灰；Smart Search 的部分是 60 帧弹簧动画。

预览在 `previews/`（关键帧）和 `out/previews/`（小样视频，用 `tools/render.mjs` 重新生成）。

## 共用设定

**角色**

- Clawd：18×10 方像素，身体 `#D97757`、下沿 `#B85F40`、眼睛 `#2A2622`，没有嘴，表情全靠眼睛。设定图见 `previews/clawd-model-sheet.jpg`。
- 道具：Smart Search 图标里的放大镜（深色镜框、淡蓝镜片）。举到眼前时镜片里的眼睛放大一倍。
- 旧放大镜：镜片发灰、有裂纹，代表内置搜索。
- Smart Search 自己的看板娘（图标里的白发少女）：片尾用真实图标出镜；要不要让她在剧情里给 Clawd 递放大镜，由你定。

**冲突里演的痛点（只演你实际遇到的，请确认）**

1. 在某些接入方式或地区，内置搜索用不了（比如经第三方 API 中转时），只能凭记忆回答。
2. 读网页只拿到模型写的摘要，拿不到原文，没法逐字引用。
3. 有些页面抓不下来。
4. 不能自选搜索服务商，没有文档检索和深度研究。

**Smart Search 这边演的优点（都来自 README 和 CLI 手册）**

- 主搜索 + 意图路由：`smart-search search`、`smart-search route`
- 文档检索、网页抓取成 Markdown 原文：`smart-search fetch`
- 输出带「主要来源 / 补充来源」链接列表，可加 `--extra-sources` 多源核对
- 深度研究：`smart-search research --budget deep`
- 服务商自选（Key 自己提供），失败时回退、冷却
- App 里看实时「活动」；关掉 App 也能用独立 CLI
- Skills 装进 Codex、Claude Code、Cursor 等 17 个工具

**贯穿示例**：README 里的原句「查 React 当前文档里 useEffect 的清理规则，读相关页面，并给出来源」。
现在的 react.dev 原文是 "After every **commit** with changed dependencies, React will first run the cleanup function (if you provided it) with the old values, and then run your setup function with the new values."
旧版文档写的是 re-render。这正好是"记忆里的版本和当前文档不一样"的真实例子，可以当成片中的小彩蛋。

**全片规矩**

- 前 3 秒出现真实命令或问题，之后每 2–4 秒有新东西；高潮放在 70–80% 处，片尾标志停 2–4 秒。
- 每段字至少停 2.5 秒；1080p 下字幕不小于 56px，辅助文字不小于 32px；静音也能看懂。
- 终端里只出现真实命令和真实输出格式，不编造报错原文；痛点用画面比喻和字幕表达。
- 避开 AI 片的默认样子：深色底配橙色、居中大字配渐变、所有元素一起淡入、发光、无意义的粒子爆炸。
- 画面只由时间 t 决定（`window.render(t)`），Playwright 逐帧截图，ffmpeg 合成；配乐和音效用 numpy 合成，响度 -14 LUFS。
- Clawd 属于 Anthropic：片尾和简介写明"非官方同人形象，与 Anthropic 无关"，不用 Anthropic / Claude 的 logo；其他 Agent 只写名字，不用它们的 logo。

### 方案 A：掉帧 → 丝滑（活的录屏）

**一句话**：同一个问题问两遍。内置搜索那半段画面卡成 8 帧、发灰；装上 Smart Search 后，画面"升级"成 60 帧，Clawd 在真实界面里搜索、读原文、带着出处回来。
**风格**：Screen Studio 式一镜录屏；暖纸色背景 `#ECE5D8`、白色窗口；Clawd 橙是画面里唯一的饱和色；Smart Search 蓝 `#728CE2` 只给来源和引用；Inter + Noto Sans SC + JetBrains Mono。
**规格**：45 秒 · 1920×1080（可加 1080×1920 竖版）· 60fps
**技术组合**：HTML/CSS/SVG + 闭式弹簧；Clawd 是 SVG 大像素精灵，高清界面里的大像素就是风格；前段 8fps 步进 + 去色，后段 60fps，快速推镜处加运动模糊；numpy 合成配乐和音效。

**画面概括**

1. 0–3s　终端里逐字打出提问；Clawd 从窗口顶边探头，眼睛跟着光标走。
2. 3–8s　【卡壳】画面掉到 8 帧、发灰。Web Search 一直转圈，Clawd 原地蹦，头顶冒问号。
3. 8–12s　Fetch 带回一张「只拿到摘要」的模糊卡片；Clawd 用裂了的旧放大镜凑近看，还是糊的；`▶▶ 4×` 快进标签表示干等。
4. 12–15s　【转折】终端敲 `npm install -g @konbakuyomu/smart-search`，Skill 装进 Claude Code；Clawd 脚下扩散一圈蓝色波纹，颜色回来，右上角 8 FPS 跳成 60 FPS。
5. 15–20s　同一个问题重来：`smart-search search` 的结果卡片瀑布式弹出；Clawd 跳上第一张卡，掏出新放大镜，镜头推近。
6. 20–26s　读原文：卡片展开成整页文档，Clawd 沿着文字行走，荧光笔扫出原话 "After every commit…"，旁边小字点出"记忆里是 re-render，现在写的是 commit"。
7. 26–31s　对照 + 回答：第二个来源飞来并排打勾；终端里回答逐字出现，句尾带 [1][2]，下面列出来源链接。（高潮）
8. 31–38s　四格快切：查文档 / 追新变化 / 核对链接里的说法 / `smart-search research` 深度研究；接 App 的「活动」页实时进度和「服务商」三类能力打勾。
9. 38–45s　窗口收成 Smart Search 图标，看板娘探头；一句「让 AI 联网查资料、读网页，回答时有来源可查。」+ 安装命令 + GitHub；Clawd 挥手。

**声音**：前段钢琴单音 + 卡顿的磁带拖音；转折处"咔哒—嗖"；后段 110 BPM 轻快 lo-fi（电钢、贝斯、轻鼓）。Clawd 的跳跃、落地、掏放大镜各配一个 8-bit 小音。不配音，靠字幕胶囊。
**预计**：渲染约 6–8 分钟 · 难点是界面重绘的工作量，以及每段字停留够久。
**适合**：信息最全、最像真实使用，适合 README、发布页和 B 站。

预览：`previews/plan-a-before.jpg`、`previews/plan-a-after.jpg`、小样 `out/previews/plan-a.mp4`

### 方案 B：Clawd 寻源记（16-bit 像素冒险）

**一句话**：把"内置搜索不好用 → 换 Smart Search"演成游戏换装备。裂了的旧放大镜、挂着「暂不可用」的大门、只写着模糊摘要的卷轴；拿到 Smart Search 放大镜后一路开门、收集出处金币、打败幻觉幽灵。
**风格**：240×135 内部分辨率 ×8 最近邻放大；约 32 色固定色板 + Bayer 抖动；精灵 12fps 阶梯动画，镜头整像素移动，关键处整数倍硬切推近；Fusion Pixel 12px 中文像素字；淡淡的扫描线。
**规格**：50 秒 · 1920×1080 · 30fps
**技术组合**：Canvas 2D 小画布 + 整数倍放大（UI 层固定 ×8，世界层 ×1 / ×2）；chiptune（方波旋律、三角波贝斯、噪声鼓）+ 金币、跳跃、开箱、幽灵音效，全部 numpy 合成。

**画面概括**

1. 0–3s　「CLAWD 寻源记」像素大字砸下，PRESS START 闪烁，一声确认音。
2. 3–9s　训练数据村：村民问「今天有什么值得关注的 AI 新闻？」Clawd 翻记忆书，日历停在「知识截止」那页，书里飘出紫色幻觉幽灵胡乱作答。
3. 9–15s　【卡壳】Clawd 拿旧放大镜出村：网页迷宫大门挂着「暂不可用」；捡到的卷轴只写着模糊的「摘要……」；旧放大镜"咔"地裂开。
4. 15–20s　【转折】光柱降下 Smart Search 放大镜，镜头硬切推近；经典"获得道具"举过头顶 + 号角，对话框「获得道具：Smart Search 放大镜！能联网搜索、读原网页，带回出处。」（也可以改成看板娘从洞里递出来：「一个人去太危险了！带上这个。」）
5. 20–30s　网页迷宫横版关卡：放大镜一照大门开锁（自选服务商 = 一串钥匙）；顶出问号砖掉出搜索结果；钻进网页读原文卷轴，字变清楚；收集出处金币 [1][2][3]，HUD「出处 ×3」。
6. 30–38s　Boss：幻觉幽灵挡路，Clawd 把三枚出处金币连发砸过去，幽灵碎成像素。（高潮）
7. 38–44s　回村交卷：答案卷轴展开，底下三行出处；村民冒爱心，日历翻到"今天"。
8. 44–50s　STAGE CLEAR 菜单：CLI / 桌面 App / 装进 Codex、Claude Code、Cursor 等 17 个工具；最后是 Smart Search 标志 + 一句话 + 安装命令，「按任意键继续」闪烁，Clawd 打盹。

**声音**：128 BPM chiptune，村庄轻快 → 迷宫加速 → Boss 紧张 → 通关号角；"获得道具"上行琶音；金币"叮"、跳跃"啾"、幽灵"呜"。
**预计**：渲染约 2 分钟（小画布很快）· 难点是像素美术量（村庄、迷宫、幽灵、村民）。
**适合**：最有梗、最好传播；游戏比喻一看就懂：道具 = 工具，金币 = 出处，幽灵 = 幻觉，锁门 = 用不了。

预览：`previews/plan-b-gate.png`、`previews/plan-b-item.png`、小样 `out/previews/plan-b.mp4`

### 方案 C：同题竞速（左右分屏）

**一句话**：同一个问题，左边内置搜索、右边 Smart Search，同时跑四个回合（搜索 → 读原文 → 核对 → 回答）。左边一路卡，右边一路"唰"；最后左边的 Clawd 翻过分界线借走放大镜。
**风格**：漫画贴纸风：粗墨线、硬投影、网点底纹；左半冷灰、8 帧抖动，右半奶油暖色、60 帧弹簧；ZCOOL 快乐体做拟声字，Noto Sans SC Black 做题目；Clawd 是带白描边的贴纸。
**规格**：35 秒 · 1920×1080（左右结构方便改成 1080×1920 上下版）· 60fps
**技术组合**：HTML/CSS/SVG + 闭式弹簧；左右两条时间轴，左边按 8fps 步进；120 BPM 节拍网格，每回合 2 小节；numpy 合成配乐和拟声音效。

**画面概括**

1. 0–3s　题目卡砸在正中「同一个问题：useEffect 的清理函数什么时候执行？」，屏幕沿锯齿线撕成两半，左「内置搜索」右「Smart Search」，READY…GO！
2. 3–9s　第 1 回合 · 搜索：右边结果卡"唰唰"弹出；左边转圈，冒出"卡……"。
3. 9–15s　第 2 回合 · 读原文：右边 Clawd 举放大镜，原文高亮 + [1]；左边只有一张糊掉的「只有摘要」卡。（预览就是这一回合）
4. 15–21s　第 3 回合 · 核对：右边两个来源并排，红线一连打勾；左边对着糊卡干瞪眼。
5. 21–27s　第 4 回合 · 回答：右边答案带 [1][2] 冲线，彩带落下；左边搜不到，只能凭记忆写出旧说法 re-render，被盖上红章「出处？」。（高潮）
6. 27–32s　反转：左边 Clawd 扒着分界线探头，伸手借走放大镜；分界线被撕掉，两边合成一个丝滑画面，打出安装命令。
7. 32–35s　Smart Search 图标 + 一句话 + GitHub；两只 Clawd 一起挥手。

**声音**：120 BPM 轻快放克（鼓 + 贝斯），左边每回合一个"嘟——"失败音，右边"唰 / 叮"；合体时一个大和弦。
**预计**：渲染约 4–5 分钟 · 难点是两边信息量要对称，字要大到手机上能看清。
**适合**：对比最直接，30 多秒节奏紧，最适合短视频平台和竖屏。

预览：`previews/plan-c-race.jpg`、小样 `out/previews/plan-c.mp4`

## 需要你定的

1. 选 A、B、C，还是混搭（比如 C 的结构 + B 的像素画风）。
2. 痛点里哪几条是你真实遇到的；片子只演这些。
3. 时长、画幅（16:9 / 9:16 / 两版都要）、要不要配音（默认不配，Clawd 发 8-bit 叽叽声 + 字幕），以及看板娘的戏份。

确认后按 xilo 流程写 `brief.md`（role / inputs / direction / structure / build / gotchas / start 七块），再逐镜头制作、自检打分到每项 8 分以上。
