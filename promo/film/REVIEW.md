# 审片记录：同一个问题

按 xilo-opus-video 的自检项打分（1–10），每轮列出最严重的问题和改法。

## 第 1 轮：逐镜头静帧

| 时间 | 问题 | 改法 |
| --- | --- | --- |
| 13–16 s | 右边 Clawd 被推镜推到右上角，压住「Smart Search 60 FPS」标签 | 右侧终端下移到 y=300，第 1 回合推镜收小到 1.06 |
| 13–14 s | 终端行太长折行，来源卡片两侧露出半截链接 | 右侧终端字号 19px；卡片加宽到 800 并对齐原来的行；被"抽走"的行透明度降到 0.06 |
| 19–23 s | 镜头跟着 Clawd 平移，原文开头被分界线切掉；译文压住原文最后一行 | 第 2 回合几乎不平移（1.02）；页面重新排版，引文上方留出 Clawd 站立的空间 |
| 18–24 s | 左半边终端和摘要卡片叠在一起，画面乱 | 第 2 回合左侧终端降到 30% 不透明度，只突出摘要卡 |
| 26–30 s | 绿色印章盖住了 [2] 来源 | 印章移到来源列表下方的空白处 |
| 34–45 s | 快切和片尾整段空白 | `vis()` 设置 `display: ''` 会退回样式表里的 `none`，改为显式 `block` |
| 31 s | 合屏时 Clawd 跳得太高，出了画面上沿 | 跳跃高度 220 → 130 |
| 41 s | 片尾 Clawd 坐在命令条上，挡住标语 | 改成落在看板娘头顶，和她一起探头 |

## v2：加入 Jev 选路（53 秒）

用户要求突出 Jev 自动选路，并指出快切里 App 侧栏的看板娘没露脸。改动和检查：

| 问题 | 改法 |
| --- | --- |
| 快切的 App 侧栏把看板娘往下推了 70px，脸被裁掉 | 换成共享的 App 组件，按真实 App 的摆法：168px 图、下沉 16px，按 150% 放大 |
| 快切里的「当前能力」页是旧版概览，现在的 App 没有这一页 | 换成真实的「服务商」页：三家依次变成已配置，Exa 测试通过 |
| Jev 面板最初压在 `Bash(…)` 那一行下面，Clawd 站上去会挡住命令 | 面板下移到 y=600，这一回合镜头拉到 0.92 倍、中心下移；「叮！」放到空白处 |
| Jev 选中的是 Exa，终端却显示「## 主要来源」和「回答正文 14 行」 | 按 `cli._format_markdown` 改为「检索结果与摘录」「证据：not_evaluated」「## 来源」；去掉没有核实过的行数 |
| 深度研究快切只有三步，没体现 Jev 的判断 | 改成四步，Jev 的两次判断用蓝底区分；Clawd 站在每一步的右端，避开上一级 |
| 声音小节写死在 45 秒的时间表上 | 配乐的小节全部从时间表推算；新增概率条上滑音和选中铃声 |

成片：53.000 秒，1920×1080，60fps，H.264 + AAC 48 kHz 立体声，11.6 MB；-14.1 LUFS，真峰值 -1.9 dBTP；blackdetect 没有黑帧。

## 配置教程（69 秒）与日常使用（62 秒）

| 问题 | 改法 |
| --- | --- |
| 安装完成后仍显示「安装 CLI」和手动下载链接 | 按 `RenderCliState`：找到兼容 CLI 后只剩「重新检测」（连接前）和「环境详情…」 |
| 配置目录路径的反斜杠被模板字符串吞掉 | 源码里写成 `\\` |
| 「正在测试未保存的修改」提示框只露出下半截 | 提示出现时镜头放宽，把提示框和测试按钮一起框进去 |
| 使用片测量时窗口还停在上一个场景的缩放状态，提示框位置算错 | 测量前把各窗口复位（`settle`） |
| 命令行一页字太小，未开始的行先露出「$」 | 字号 28/30px；每行在开始打字时才出现；这一页隐藏鼠标 |
| 教程配乐太轻、点击声太尖，真峰值超过 -1 dBTP | 提高配乐、软化点击声，构建最后再加一道限幅：配置教程 -14.2 LUFS / -2.0 dBTP，日常使用 -14.5 LUFS / -1.9 dBTP |
| 镜头一直在推拉，GIF 每帧整屏都变，压出来 11–15 MB | `?gif` 模式在机位之间直接切换：README 的四张 GIF 共 7.3 MB |

两支教程都渲染为 1920×1080、60fps，没有黑帧；配置教程 29.9 MB，日常使用 23.4 MB。
